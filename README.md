# 🛒 E-commerce Frontend (Angular)

Modern E-commerce frontend application built using Angular.

##  Features

- User Authentication (Login / Register)
- Product Listing
- Add to Cart
- Cart Management
- Order Placement
- Order History & Details

## Tech Stack

- Angular
- TypeScript
- HTML, CSS
- REST API Integration

## Backend Repository

👉 https://github.com/ravipratapsingh-dev/ecommerce-backend

## Run Locally

npm install  
ng serve
